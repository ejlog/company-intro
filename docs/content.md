# 홈페이지 원고

IR 자료(표지 기준 2026.08, 48쪽)에서 홈페이지에 실을 내용을 고른 문서다.
괄호 안 `p.N`은 IR 쪽 번호. 디자인과 구현은 이 문서를 원고로 삼는다.

## 선별 원칙

- **싣는다:** 회사가 무엇을 하는지, 어떤 기술로 하는지, 어디까지 왔는지.
- **뺀다:** 대표 휴대전화, 직원·학생연구원 사진과 실명, 매출·영업이익 전망, 확약서·MOU 스캔본, 동원F&B 재무 현황과 투자 계획, 경쟁사 실명 비교표, 타사 제품·로고 사진, 시장 통계 그래프.
- **고객사·협력사 실명은 공개한다** (사용자 결정).
- **목표 수치는 목표라고 쓴다.** IR의 정확도·불량률 숫자는 대부분 과제 목표이지 달성 실적이 아니다. "90% 이상 달성"이 아니라 "90% 이상을 목표로"라고 적는다.

## 3. 기술 `/technology`

### 피지컬 AI (p.30, 31)

**현실 세계의 물리적 환경을 인식하고, 판단하고, 실제 행동까지 수행하는 인공지능.**

흐름: 인식(Perception) → 판단(Decision) → 행동(Action)

| | |
|---|---|
| 실시간 인식 | AI 비전과 다양한 센서로 객체와 환경을 실시간으로 인식하고 정밀하게 분석합니다. |
| 자율 판단·제어 | 딥러닝 기반 판단 알고리즘으로 로봇과 자동화 장비를 자율적으로 제어합니다. |
| 산업 맞춤형 AI | 수산물 자동 두절, 부산물 분류, 의료기기 등 산업 환경에 맞춘 솔루션을 제공합니다. |
| 통합 Physical AI | 인식 → 판단 → 계획 → 행동 전 과정을 하나로 묶습니다. |

적용 분야 (p.31)

## 4. 사업 `/business`

각 사업은 같은 틀로 쓴다: 한 줄 소개 → 무엇을 푸는가 → 어떻게 → 목표 → 현재 단계.

### 4.1 지능형 낙상·욕창 예방 매트리스-가드 폐루프 시스템 (p.7–9, 33)

- **한 줄:** AI 비전 기반 비접촉 자세 분석으로 욕창과 낙상을 함께 예방하는 병상 시스템.
- **배경:** 대한민국은 2025년 65세 이상 인구 1,050만 명의 초고령 사회에 진입했습니다. 고령 환자의 욕창과 낙상은 함께 늘고 있습니다.
- **구성:** RGB-D 카메라(자세·관절·무게중심 인식) + 공압 매트리스(체압 분산) + 자동 보호 가드.
- **차별점:** 실시간 모니터링, 안전 가드, 액추에이터 동작, AI 판단, 알림을 한 시스템에 담았습니다. 감지에서 끝나지 않고 대응까지 합니다.
- **목표**
  - 다양한 병실 조건에서 인체 인식 정확도 90% 이상
  - 욕창·낙상 전조 발생 시 0.5초 안에 감지–판단–제어
  - 통합 대시보드와 알림·이력 기록
- **현재 단계:** 자세·관절·무게중심 인식과 위험도 예측 알고리즘 개발 중. 실시간 모니터링 대시보드 구현 완료. 이후 병원 환경 성능평가와 의료기기 인증을 추진합니다.
- **지원 과제:** 2026년 비대면 의생명 의료기기 산업 육성 플랫폼 기반구축사업 (김해의생명산업진흥원, 2026.03–2026.10, 주관)
- **협력처:** 김해한솔재활요양병원, 성운요양병원, (주)티에이치케이컴퍼니, 제넥스(주) (구매의향 확약) / 창원경상국립대학교병원 (실증)
- **이미지:** `bed-system.jpg`, `bed-hospital.jpg`, `bed-heatmap.jpg`

### 4.2 AI 비전 기반 가다랑어 두절 자동화 시스템 (p.11–13, 34–37)

- **한 줄:** AI 비전이 가다랑어의 목 부분 절단 위치를 찾고, 로봇이 자릅니다.
- **배경:** 두절 공정은 작업자 숙련도에 크게 기댑니다. 원물 크기와 형상이 제각각이라 절단 위치를 판단하기 어렵고, 저온·습윤 환경의 반복 작업이라 인력 확보도 어렵습니다.
- **흐름:** 인식 → 판단 → 행동 → 학습. 고해상도 카메라와 다중 조명으로 원물을 스캔하고, 딥러닝 모델이 절단 위치를 정하면 로봇이 두절합니다. 작업 데이터는 다시 모델 학습에 쓰입니다.
- **기대 효과:** 절단 오차와 부산물 손상 최소화, 균일한 품질, 실시간 공정 모니터링.
- **현재 단계:** YOLO 기반 두절 위치 인식 모델 개발과 라벨링 데이터 구축 중. 자동 두절 시제품 제작과 현장 실증을 준비하고 있습니다.
- **지원 과제:** 디지털혁신챌린지 1단계 (경남테크노파크, 2025.04–2025.11, 완료) / 2단계 (2026.03–2026.10, 진행 중)
- **협력처:** 동원F&B (도입의사 확약), 국립창원대학교 산학협력단 (구조 해석·절단 메커니즘)
- **이미지:** `tuna-line.jpg`, `tuna-detect.jpg`, `tuna-sizes.jpg`

### 4.3 AI 비전 기반 가다랑어 부산물 자동 분류 (p.15–18, 38–39)

- **한 줄:** 섞여 나오는 가다랑어 부산물을 AI가 부위별로 구분해 고부가가치 자원으로 회수합니다.
- **배경:** 정소·알·심장·위 등 부산물이 섞여 배출되고, 혈액과 점액 때문에 형태와 색을 구분하기 어렵습니다. 머리·정소·껍질은 기능성 식품, 화장품, 바이오의료 소재로 쓸 수 있습니다. 경남은 2021년 기준 국내 수산부산물 발생량의 약 30.2%를 차지합니다.
- **목표**
  - 현 단계: 정소·알 2종 표준 분류 기준과 이미지 데이터셋 구축, 분류 정확도 90% 이상
  - 후속: 심장·간·껍질 등 5종 이상으로 확대, 정확도 95% 이상·오분류율 5% 이하
- **현재 단계:** 부산물 영상 데이터 구축과 객체별 라벨링 완료. CNN·YOLO 기반 모델로 정소·알 분류 정확도를 높이는 중이며, 실제 생산라인 데이터로 검증하고 있습니다.
- **지원 과제:** 2026년 경남 오픈이노베이션 공동과제 지원사업 (경남창조혁신센터, 2026.06–2026.12, 주관)
- **협력처:** 동원F&B 창원공장 (현장 실증)
- **이미지:** `byproduct-line.jpg`, `byproduct-label.jpg`

### 4.4 MES-HACCP 통합 AI 기반 스마트 팩토리 (p.20–22, 41–43)

- **한 줄:** MES와 HACCP 데이터를 연결해 공정 이상을 미리 잡고, X-Ray 이물검사와 로봇 선별을 자동화합니다.
- **배경:** 식품 공정은 설비가 낡고 네트워크로 묶여 있지 않아 데이터 수집이 어렵습니다. 중요관리점(CCP) 기록은 수기에 의존하고, 골뱅이 패각처럼 비정형 이물은 기존 장비로 걸러내기 어렵습니다.
- **두 갈래**
  - MES-HACCP 연계 공정 이상 사전 대응: 설비·MES·HACCP 데이터를 묶어 이상을 실시간 감지하고 위험 구간을 예측합니다.
  - AI 기반 X-Ray 이물검사와 로봇 자동 선별: 골뱅이 라인에서 먼저 실증합니다.
- **목표 (골뱅이 라인 기준)**
  - 공정 불량률 10% 이상 감소
  - AI 불량 검출 정확도 97% 이상, 불량 예측 정확도 97% 이상
  - 검사·조치·점검·품질 이력 통합 DB
- **현재 단계:** MES·HACCP·설비 데이터를 통합 수집해 관리하고 있습니다. 정상·이상 공정 패턴을 학습하는 이상 탐지 기능을 구현 중입니다.
- **지원 과제:** 2026년 중기부 AX-Sprint 사업 (중소벤처기업부, 2026.07–2027.07, 참여)
- **협력처:** 동원F&B
- **이미지:** `haccp-overview.jpg`, `haccp-dashboard.jpg`
